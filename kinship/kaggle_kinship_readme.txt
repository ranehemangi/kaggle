Title: Comprehensive Marathi Kinship Lexicon with Linguistic Annotations

Subtitle: 110 Kinship Terms with Morphosyntactic and Semantic Features

Description: This dataset provides a curated list of 110 kinship terms in Marathi, annotated with detailed linguistic properties. The terms cover a range of family relationships along with their English equivalents and important linguistic metadata. 

Each row in the dataset includes:
	Marathi Term
	English Translation
	Part of Speech (e.g., Noun)
	Semantic Domain (e.g., Kinship term)
	Gender (Masculine / Feminine)
	Grammatical Number (Singular / Plural)
	Animacy (Animate / Inanimate)
	Inalienability (Inalienable vs. Alienable possession)

Format: Clean and filterable Excel
